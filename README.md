# Simple Interest Calculator

## Overview
A simple web application that calculates simple interest on a loan or
investment, based on the principal, rate of interest, and time period.

## Formula
Simple Interest = (P × R × T) / 100

- P = Principal amount
- R = Annual rate of interest (%)
- T = Time period (in years)

## Features
- Accepts principal, rate, and number of years as inputs
- Displays the calculated interest and the maturity year
- Basic input validation (principal must be a positive number)

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository:
   `git clone https://github.com/your-username/simple-interest-calculator.git`
2. Open `index.html` in your browser.
3. Enter the principal, select the rate, choose the number of years,
   and click **Compute Interest**.
